# How to ask me questions

1. **Default:** questions go at the end of your message, in plain text.
2. **A multiple-choice picker only when** a question has several real alternatives with
   different consequences (for example, "install into the global Python or a project
   venv?"). Never for yes/no or go/no-go questions: write those.
3. **All open questions at once:** at most 3 multiple-choice questions in one picker; any
   others, and anything that needs a written answer, numbered in the text of the same
   message.
4. **The written report always comes first and in full.** A picker or an end-of-turn
   question box never replaces it.

Why: 2026-10-19. A multiple-choice picker with real options was useful. End-of-turn
question boxes used for simple "go?" confirmations were not, and several times they
replaced the report, so I had to ask what had been done.
